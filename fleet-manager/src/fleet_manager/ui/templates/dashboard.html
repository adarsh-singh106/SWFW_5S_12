Guided SSH Node Onboarding

✓ 1. Node Inventory Registered Done

Endpoint address and SSH port recorded in inventory.

2 2. Server Identity (Host-Key Trust)

The remote server must present its host public key. Fleet Manager rejects unknown host keys until you explicitly verify its SHA-256 fingerprint against the target server console. 


            

              
            

          

        


        
        

          

            3 3. Client Authentication (~/.ssh/authorized_keys)
          

          

            Fleet Manager authenticates using its configured private key. The operator public key must be provisioned in the remote user's authorized_keys.
          

          

            
Copyable bootstrap command for target server:

            
echo "ssh-ed25519 AAAAC3... fleet-manager-operator" >> ~/.ssh/authorized_keys && chmod 600 ~/.ssh/authorized_keys

            

              Note: Private keys are never exposed in browser or database.
            

          

        


        
        

          

            4 4. Validate SSH Verification
            
          

          

            Executes bounded connection, host-key verification, and cryptographic login.
          

        


        
        

          

            ✓ 5. Node Operationally Ready
            READY
          

          

            Current endpoint, host identity and client credentials have passed SSH authentication. Check connectivity freshness separately before acting.
